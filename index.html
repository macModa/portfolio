Projet IoT personnel

ESP32 Smart Farm Monitoring System

Pipeline IoT de bout en bout : les capteurs ESP32 publient la télémétrie du sol via MQTT vers un broker EMQX, auto-ingérée dans MongoDB via un backend Django REST Framework. Un moteur d'analyse génère des recommandations d'irrigation assistées par IA, visualisées en temps réel sur un dashboard Flutter — conteneurisé avec Docker et déployé sur Azure.
